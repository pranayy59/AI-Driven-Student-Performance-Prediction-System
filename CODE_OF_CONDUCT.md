# Code of Conduct

## Our Pledge

This project welcomes respectful collaboration and constructive feedback.

## Expected Behavior

- Use professional and inclusive language.
- Respect different skill levels and viewpoints.
- Focus feedback on improving the project.
- Avoid sharing private or sensitive information.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Disruptive or intentionally harmful conduct.

## Enforcement

Maintainers may remove inappropriate content or decline contributions that violate this code of conduct.
